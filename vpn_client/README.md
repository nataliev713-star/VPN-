# Pink Service VPN — Оболочка

Клиент и оболочка для подключения к серверам подписки Pink Service (VLESS Reality / gRPC).

## Быстрый запуск

- **Графический интерфейс (GUI):**
  Дважды кликните по файлу `start_vpn_gui.bat` в корне проекта.
  *(Или: `python vpn_client/main.py`)*

- **Консольный интерфейс (CLI):**
  Дважды кликните по файлу `start_vpn_cli.bat` в корне проекта.
  *(Или: `python vpn_client/main.py --cli`)*

## Возможности

1. **26 серверов**: Нидерланды, Германия, США, Польша, Франция, Швеция, Турция, Казахстан, Россия и др.
2. **Ядро Xray 26.11.9**: Автоматически настроено в папке `bin/`.
3. **Автоматический HWID**: Обход блокировок и корректная авторизация в Pink Service.
4. **Управление системным прокси Windows**: Включает прокси в один клик для всей системы (браузеры, приложения, игры) и автоматически сбрасывает при отключении.
5. **Локальные порты подключения**:
   - **SOCKS5**: `127.0.0.1:20808`
   - **HTTP**: `127.0.0.1:20809`
6. **Тест пинга и проверка внешнего IP/геолокации**.
