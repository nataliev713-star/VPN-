# Shadowrocket Replica (iOS)

Нативная реплика **Shadowrocket** на **SwiftUI** с исправлением главных проблем оригинала:
1. **Честный HTTP 204 Ping** вместо фиктивного TCP-хэндшейка.
2. **Защита от утечек DNS** через принудительный DoH (`1.1.1.1` / `8.8.8.8`) в `PacketTunnelProvider`.
3. **Оптимизация памяти (<15 МБ)** для защиты от выгрузки в фоне на iOS.
4. **Поддержка современных протоколов**: VLESS, VMess, Shadowsocks, Trojan.

## Инструкция по сборке и установке БЕЗ ПК (прямо с iPhone)

1. **Создайте репозиторий на GitHub** и загрузите эти файлы.
2. Откройте вкладку **Actions** в мобильном Safari:
   - Воркфлоу `Build Shadowrocket Replica IPA` запустится автоматически.
   - Сборка на macOS-раннере займет около 2 минут.
3. Скачайте готовый артефакт `Shadowrocket-Replica-IPA` из браузера телефона.
4. Откройте приложение **ESign / GBox** на iPhone:
   - Нажмите *«Поделиться»* -> Импортировать в ESign.
   - Подпишите файл вашим годовым сертификатом разработчика (`.p12` + `.mobileprovision`).
   - Нажмите *«Установить»*.

Приложение установится на домашний экран и будет работать 365 дней без необходимости повторной подписи или подключения к компьютеру.
